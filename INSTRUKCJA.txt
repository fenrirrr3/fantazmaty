2. Podgląd importu (bez zapisu):

3. Po sprawdzeniu raportu zapis:
python manage.py import_extract_volumes import_ekstrakty.json --create-missing-people --apply --report raport_ekstrakty_zapis.json

4. Dopiero potem wcześniejszy import korekty poskładowej:
python manage.py import_post_layout_credits import_poskladowa.json --report raport_poskladowa_podglad.json
python -m json.tool --no-ensure-ascii raport_poskladowa_podglad.json
python manage.py import_post_layout_credits import_poskladowa.json --apply --report raport_poskladowa_zapis.json

5. PythonAnywhere: Web → Reload.
collectstatic nie jest potrzebne: paczka nie zmienia plików CSS ani JS.

OSOBY I ROZBIEŻNOŚCI
Zgodnie z ustaleniami: Arek Nowakowski → Arkadiusz Nowakowski; Ilona Skrzypczak → Ilona Żurawska. Oryginalne podpisy pozostają zapisane przy pracach. Innych nazwisk ani skrótów imion nie łączono przez zgadywanie.
--create-missing-people pozwala utworzyć brakujący nieaktywny profil bez e-maila i bez nowych ról. Nie tworzy kont użytkowników. Jeśli jest jedno zgodne istniejące konto bez profilu, wiąże nowy profil z tym kontem; nie zmienia konta. Bez tej opcji brak osoby zatrzymuje import. Podgląd pokazuje wszystkie takie działania, a następnie je wycofuje.
Przy wielu pasujących osobach import przerywa całość. Tak samo przy nieznanej nazwie naboru, istniejącej antologii bez znacznika tego importu lub konflikcie danych. Raport jest JSON, nie HTML.
Jawne mapowanie można przekazać przez --map mapa_ekstrakty.json, zarówno do podglądu, jak i zapisu. Format:
{"people": {"Podpis ze stopki": 123}, "recruitments": {"Nazwa naboru z bazy": 1}}
123 to przykład: należy podać ID profilu Osoba, NIE ID konta użytkownika. Numer tomu to 1, 2 lub 3. Domyślnie rozpoznaje Ekstrakty, Ekstrakty 1/2/3 i Ekstrakty I/II/III.

Ponowny import nie dubluje tych samych tekstów i przypisań. Nie usuwa tekstów, które po imporcie zniknęły z listy przyjętych: zatrzymuje się do wyjaśnienia. Nie aktualizuje późniejszych zmian workflow ani tytułów już powiązanych miniatur.
Uruchamiaj oba importy kolejno, pojedynczo. Błąd w imporcie Ekstraktów wycofuje całą jego transakcję; wcześniejszy import korekty poskładowej ma własną transakcję.
