## Ujednolicenie CSS

- `themes.css` przechowuje wspólną paletę jasnego i ciemnego motywu. Podstawowe
  kolory przeniesiono ze `styles.css`, zachowując ich dotychczasowe wartości.
- Przyciski główne, zakończenia i akceptacji korzystają ze wspólnych zmiennych
  tła, obramowania, tekstu i hover. Usunięto odrębne kopie tych samych reguł
  dla ciemnego motywu. Przycisk wyboru DOCX korzysta z tej samej palety.
- Oznaczenia tak/nie, ważne uwagi i uwagi koordynatora korzystają ze wspólnych
  kolorów sukcesu, ostrzeżenia i błędu. Poprawiono kaskadę obramowania panelu
  koordynatora, wcześniej nadpisywanego ogólnym stylem paneli.
- Placeholdery respektują motyw. Rozwijane panele mają wspólny fokus klawiatury;
  formularz nowych wykonań ma spójne odstępy etykiet i pól.
- Zachowano układ tabel, progi responsywne, nawigację, reguły druku i białe
  teksty pomocnicze ciemnego motywu. Zaktualizowano wersje arkuszy w szablonie.

Nie połączono wszystkich arkuszy w jeden plik: style admina korzystają z palety
Django, a style importu i programów są ładowane tylko tam, gdzie są potrzebne.
Parser nie znalazł błędów w żadnym z ośmiu arkuszy. Cztery zmienne admina
(`--body-bg`, `--body-fg`, `--hairline-color`, `--link-fg`) dostarcza Django;
nie są brakującymi zmiennymi motywu CMS. Kontrola CSS i renderowanie HTML nie
zastępują kontroli pikselowej na desktopie i telefonie.

## Wdrożenie

Rozpakuj paczkę w katalogu z `manage.py`, zachowując ścieżki. Jest zbiorcza:
obejmuje wszystkie wcześniejsze poprawki tej rozmowy, tylko nowe/zmienione pliki
względem archiwum `fantazmaty(20261002-130616).zip`.

W interpreterze używanym przez aplikację:

```bash
python manage.py migrate
python manage.py collectstatic --noinput
```

Następnie zrestartuj aplikację i odśwież stronę. Jeżeli migracje 0011–0013 są
już wykonane, audyt nie dodaje nowych migracji ani nie uruchamia ich ponownie.
Zachowano ich dotychczasową zawartość. Polecenie aktualizacji samej bazy lokalnej
pozostaje: `python manage.py migrate`.

Jeżeli po wykonaniu migracji powstały kolejne zwykłe duplikaty, dostępny jest
podgląd i osobny zapis scalenia:

```bash
python scal_przypisania.py
python scal_przypisania.py --apply
```

Jawne powtórzenia i przekazania nie są duplikatami do usuwania. Istniejący
raport scalenia wypisuje grupy i rekord zachowany; nie odtwarza pełnych danych
rekordów usuniętych we wcześniejszym uruchomieniu. Do odtworzenia takiej listy
potrzebny jest zapis wyniku operacji lub kopia bazy sprzed scalenia.

Jeżeli pojawia się `No module named 'docx'`, zainstaluj zadeklarowane zależności
w tym samym interpreterze: `python -m pip install -r requirements.txt`.
Nazwa pakietu to `python-docx`. Nie resetuj używanej bazy ani historii migracji.
